Platform Execution & Download Compatibility Guide

Why Android & Mac need specific permissions and how to run them in under 10 seconds

Android Solution Why APK didn't open & Working Fix:

Android OS Package Installer blocks raw zip/web packages with "There was a problem parsing the package" because Android requires Google Play / SDK compiled binary Dalvik bytecode (classes.dex) and cryptographic signing.

✅ 2 Guaranteed Ways to Run on Android:
  1. Instant 0-Install: Open QueueLess-Standalone-Mobile.html in Chrome. Works 100% offline!
  2. Native Home Screen WebAPK: Open in Chrome → Tap (⋮) menu → Tap "Install app" or "Add to Home screen". Android generates a signed native launcher icon!
Open Mobile App Directly on Phone
macOS (Mac) Solution Why DMG/Command didn't open & Fix:

macOS automatically strips the executable permission bit (+x) when files are downloaded from Windows/Web (gives "no appropriate access privileges"), and Apple Gatekeeper quarantines unsigned binaries.

✅ 2 Guaranteed Ways to Run on Mac:
  1. One Terminal Command: Run chmod +x Launch-QueueLess-Mac.command and double click!
  2. Native Safari App: Double click index.html in Safari → Click File → Add to Dock.... macOS turns it into a real Mac desktop app!
Download Fixed Mac Launcher (.command)
Host on Local Wi-Fi (Run on Phone, Mac, and PC simultaneously):
Double-click start-server.bat on your PC. It prints a local Wi-Fi URL like http://192.168.x.x:5000.

Any Android phone, iPhone, or Mac connected to the same Wi-Fi can open that URL in their browser and immediately use QueueLess in real-time sync!
